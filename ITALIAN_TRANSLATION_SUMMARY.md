## 🔑 Key Terminology Glossary (Quick Reference)

| English | Italian | Context |
|---------|---------|---------|
| User | Utente | Always singular when generic |
| Premium tier | Piano premium | "Tier" can be "piano" or "livello" |
| Free tier | Piano gratuito | Not "tier gratis" |
| Streak | Serie | "Serie consecutiva" when ambiguous |
| Daily limit | Limite giornaliero | Not "limite del giorno" |
| Paywall | Paywall / Soft paywall | Acquired term |
| Feature | Funzionalità | Preferred over "caratteristica" |
| Upgrade | Aggiornamento / Upgrade | Context-dependent |
| Badge | Badge | Gaming term acquired in Italian |
| Milestone | Traguardo | Not "pietra miliare" |
| Check-in | Check-in | Acquired term |
| Backend/Frontend | Backend/Frontend | Kept in English |
| API | API | Feminine: "l'API" |
