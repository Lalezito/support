## 🎯 Standard Traduzione Applicati

### 1. Scelta Formalità: "TU" (Informale)

**Decisione:** Utilizzare forma informale "tu" invece di formale "Lei"

**Motivazione:**
- App personale per astrologia/benessere
- Target demografico giovane-adulto (18-45 anni)
- Stile comunicazione amichevole e accessibile
- Coerente con tono app esistente

**Esempi:**
- ✅ "Hai raggiunto il tuo limite giornaliero"
- ❌ "Ha raggiunto il Suo limite giornaliero"
- ✅ "La tua energia Leone"
- ❌ "La Sua energia Leone"

### 2. Termini Tecnici

#### Mantenuti in Inglese:
- Backend
- Frontend
- API
- Chat
- Flutter
- JavaScript
- Database
- JSON
- UUID
- HTTP
- Token
- Workflow
- Testing
- Debug
- Deployment

**Motivazione:** Terminologia standard industria IT, comprensibile a sviluppatori italiani

#### Tradotti:
- User → Utente
- Feature → Funzionalità / Caratteristica
- Premium tier → Piano premium / Livello premium
- Message → Messaggio
- Daily limit → Limite giornaliero
- Streak → Serie (consecutiva)
- Memory → Memoria
- Prediction → Predizione
- Free tier → Piano gratuito
- Upgrade → Aggiornamento / Upgrade (contesto)

### 3. Accenti e Ortografia Italiana

**Applicazione Corretta:**
- à, è, é, ì, ò, ù (accenti gravi e acuti)
- Apostrofi: l'utente, un'applicazione, dell'API
- Maiuscole: Solo nomi propri (Leone, Google, Cosmic Coach)
- Numeri: 5.000 (punto migliaia), 70,5% (virgola decimale)

**Esempi Corretti:**
- "È possibile" (non "E' possibile")
- "Più efficiente" (non "Piu efficiente")
- "Così importante" (non "Cosi importante")
- "L'API restituisce" (non "La API restituisce")
