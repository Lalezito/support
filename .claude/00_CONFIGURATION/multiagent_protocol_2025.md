# 🤝 PROTOCOLO MULTI-AGENTE AUTOMÁTICO

## **ACUERDO DE FUNCIONAMIENTO**

### **REGLA AUTOMÁTICA:**
**Cada vez que reciba una instrucción, SIEMPRE ejecutaré:**

1. **TodoWrite automático** - Plan de la tarea
2. **Análisis de agentes necesarios** - Qué expertos usar
3. **Task tool en paralelo** - Lanzar múltiples agentes
4. **Coordinación de resultados** - Consolidar respuestas
5. **Implementación directa** - Ejecutar soluciones

### **WORKFLOW ESTÁNDAR:**

#### **PASO 1: ANÁLISIS AUTOMÁTICO (5 segundos)**
```
Instrucción recibida → Clasificar tipo:
- 🔧 Technical (Flutter + Backend)
- 💰 Business (Business + Flutter)
- 🚀 Deployment (Todos + Plans)
- 📊 Analysis (Status + Específicos)
- 🐛 Bug fix (Flutter + Backend si needed)
```

#### **PASO 2: PLAN AUTOMÁTICO (TodoWrite)**
```
Crear TODO list inmediatamente:
□ Analizar requerimiento específico
□ Identificar agentes necesarios
□ Lanzar Task tools en paralelo
□ Consolidar resultados
□ Implementar solución
```

#### **PASO 3: EJECUCIÓN MULTI-AGENTE**
```
Lanzar en paralelo (Task tool):
- Agent 1: Análisis específico
- Agent 2: Implementación técnica
- Agent 3: Business impact
- Agent 4: Testing/validation
```

#### **PASO 4: CONSOLIDACIÓN Y ENTREGA**
```
- Combinar insights de todos los agentes
- Generar solución unificada
- Implementar cambios directamente
- Reportar resultados completos
```
