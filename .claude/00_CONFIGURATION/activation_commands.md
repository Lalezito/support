# ⚡ COMANDOS DE ACTIVACIÓN MULTI-AGENTE

## **COMANDOS RÁPIDOS**

### **Activación Global:**
```
"/multi" → Activa protocolo automático para esta sesión
"/plan" → TodoWrite + análisis + agentes sugeridos
"/agents" → Lanza agentes apropiados en paralelo
"/execute" → Plan + agentes + implementación completa
```

### **Activación por Tipo:**
```
"/dev" → Flutter + Backend experts automático
"/biz" → Business + monetización focus
"/deploy" → Deployment + launch preparation
"/fix" → Bug analysis + solution implementation
"/optimize" → Performance + conversion optimization
```

### **Ejemplo de Uso:**
```
Usuario: "/multi implementa calendar sync con neural compatibility"
Sistema:
1. TodoWrite automático con pasos
2. Task tool: Flutter expert + Backend expert en paralelo
3. Implementación coordinada
4. Testing y validation
5. Resultados consolidados
```

## **CONFIGURACIÓN PERMANENTE**

Puedes hacer que esto sea permanente agregando a tu configuración:

```json
{
  "auto_multiagent": true,
  "trigger_keywords": [
    "implementa", "agrega", "fix", "optimiza",
    "deploy", "launch", "analiza", "mejora"
  ],
  "default_behavior": "plan_first_then_execute"
}
```
