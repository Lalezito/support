```bash

open -a Simulator

# En Simulator:
# Device > iPhone 15 Pro (1290x2796)
# Cmd+S para screenshot
```

### **Opción 2: Dispositivo físico**
```bash
# Conectar iPhone
# Settings > Display > Screenshot format > PNG
# Usar botón home + power para capturar
```

### **Opción 3: Android Emulator**
```bash
# En Android Studio:
# AVD Manager > Create Virtual Device
# Pixel 6 (1080x1920)
# Extended Controls > Camera > Screenshot
```
