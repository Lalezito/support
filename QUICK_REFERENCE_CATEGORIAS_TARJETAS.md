## 📁 Archivo

**Ubicación:** `lib/services/cosmic_coach/category_translations.dart`

**Función:**
```dart
CategoryTranslations.getCategoryLabel('adventure', 'es')
// → 'AVENTURA'

CategoryTranslations.getCategoryLabel('career', 'de')
// → 'KARRIERE'

CategoryTranslations.getCategoryLabel('wellness', 'fr')
// → 'BIEN-ÊTRE'
```
