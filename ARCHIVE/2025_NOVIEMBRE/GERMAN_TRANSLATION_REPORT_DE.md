## ÜBERSETZUNGSRICHTLINIEN EINGEHALTEN

### ✅ Deutsche Standards

1. **Formelles "Sie"**
   - Durchgängig formelle Ansprache verwendet
   - "Sie haben", "Ihr System", "Überprüfen Sie"

2. **Substantivgroßschreibung**
   - Alle Substantive großgeschrieben (Standard Deutsch)
   - Beispiel: "Benutzer", "Datenbank", "Anwendung", "Service"

3. **Zusammengesetzte Wörter**
   - Deutsche Kompositbildung genutzt
   - Beispiele: "Datenbankschema", "Benutzerprofileinstellung", "Antwortformat"

4. **Technische Präzision**
   - Fachlich korrekte Terminologie
   - Klare, präzise Formulierungen

### ✅ Technische Begriffe (Mix-Ansatz)

**Auf Englisch belassen:**
- Backend
- Frontend
- API
- Chat
- Flutter
- JavaScript
- JSON
- ChatGPT
- OpenAI
- PostgreSQL
- Redis
- JWT
- HTTP
- UUID

**Ins Deutsche übersetzt:**
- Database → Datenbank
- User → Benutzer
- Message → Nachricht
- Daily limit → Tageslimit
- Feature → Funktion / Funktionalität
- Streak → Serie
- Premium tier → Premium-Stufe
- Check-in → Check-in / Einchecken
- Feedback → Rückmeldung / Feedback

**Hybrid (erklärt):**
- "Premium-Tier (Premium-Stufe)"
- "Check-in (Einchecken)"
- "Streak-System (Serien-System)"

## HERAUSFORDERUNGEN & LÖSUNGEN

### Herausforderung 1: Technische Begriffe
**Problem:** Entscheidung, welche Begriffe zu übersetzen sind
**Lösung:**
- Allgemein bekannte Begriffe beibehalten (API, Backend, Frontend)
- Benutzerorientierte Begriffe übersetzen (User → Benutzer, Message → Nachricht)
- Bei Hybrid beide Formen angeben: "Premium-Tier (Premium-Stufe)"

### Herausforderung 2: Code-Kommentare
**Problem:** Code-Kommentare sind auf Spanisch/Englisch
**Lösung:**
- Code-Kommentare NICHT übersetzt (würden Code brechen)
- Deutsche Erklärungen außerhalb der Code-Blöcke hinzugefügt
- Beispiel: "// Zeile 98 in aiCoachService.js ändern" (Deutsch) + Code unverändert

### Herausforderung 3: Mehrsprachige Beispiele
**Problem:** Beispiele in 6 Sprachen (ES, EN, PT, FR, DE, IT)
**Lösung:**
- Originalsprachen-Beispiele beibehalten
- Deutsche Kontextbeschreibungen hinzugefügt
- Tabellen mit Sprachbeispielen unverändert

### Herausforderung 4: Slang & Redewendungen
**Problem:** Regionale Slang-Wörter (argentinisches "che", mexikanisches "wey")
**Lösung:**
- Slang NICHT übersetzt (sprachspezifisch)
- Deutsche Erklärungen in Beschreibungen
- Beispiel: "Voseo (vos, tenés, podés)" mit deutscher Erklärung

### Herausforderung 5: Lange deutsche Komposita
**Problem:** Deutsch erzeugt sehr lange Wörter
**Lösung:**
- Akzeptiert als normale deutsche Sprachpraxis
- Beispiele: "Datenbankmigrationsausführung", "Benutzerprofileinstellung"
- Wo nötig mit Bindestrichen: "Premium-Konversionsrate"
