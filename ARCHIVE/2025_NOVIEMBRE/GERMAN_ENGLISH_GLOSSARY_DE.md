## VERWENDUNGSHINWEISE

### Kategoriendefinitionen

**🟢 Übersetzt (Deutsch)** - Vollständig deutsche Begriffe
- Beispiel: User → **Benutzer**

**🔵 Unverändert (Englisch)** - Englische Fachbegriffe beibehalten
- Beispiel: Backend, API, Frontend

**🟡 Hybrid** - Beide Formen in Dokumentation
- Beispiel: Premium-Tier (Premium-Stufe)

**🟣 Kontextabhängig** - Je nach Kontext unterschiedlich
- Beispiel: Feature → Funktion / Funktionalität

### Verwendungsregeln

1. **Konsistenz:** Immer denselben Begriff für dasselbe Konzept verwenden
2. **Klarheit:** Bei Unklarheit Hybrid-Form verwenden
3. **Zielgruppe:** Entwickler verstehen englische Fachbegriffe
4. **Deutsche Standards:** Alle Substantive großschreiben

## SPEZIELLE ÜBERSETZUNGSREGELN

### Zusammengesetzte Wörter

**Deutsche Komposita bevorzugen:**
- user_id → Benutzer-ID
- database schema → Datenbankschema
- API endpoint → API-Endpunkt
- error handling → Fehlerbehandlung

**Mit Bindestrichen bei Hybrid-Begriffen:**
- premium tier → Premium-Tier
- check-in system → Check-in-System
- paywall logic → Paywall-Logik

### Code-Begriffe in Dokumentation

**Variablen/Funktionsnamen:** Unverändert
```javascript
// Code bleibt auf Englisch
const memoryService = require('./memoryService');
await streakService.checkIn(userId, language);
```

**Erklärungen:** Auf Deutsch
- "Die `memoryService`-Funktion extrahiert Erinnerungen..."
- "Rufen Sie `streakService.checkIn()` auf, um..."

### Dateinamen & Pfade

**Unverändert lassen:**
```
/backend/flutter-horoscope-backend/src/services/aiCoachService.js
```

**Deutsche Erklärung:**
- "Die Datei `aiCoachService.js` im Backend-Services-Ordner..."

## HÄUFIGE FEHLER VERMEIDEN

### ❌ FALSCH

1. "Der User sendet eine Message zum Backend."
   - **Problem:** Deutsch/Englisch gemischt ohne Konsistenz

2. "Die database speichert die data in einer table."
   - **Problem:** Zu viele englische Begriffe ohne Übersetzung

3. "Der Benutzer upgradet auf Premium Tier."
   - **Problem:** Verb falsch gebildet ("upgraden" statt "upgradet")

4. "Das memory system speichert memories."
   - **Problem:** Inkonsistente Übersetzung

### ✅ RICHTIG

1. "Der Benutzer sendet eine Nachricht zum Backend."
   - **Konsistent übersetzt** + **Backend bleibt**

2. "Die Datenbank speichert die Daten in einer Tabelle."
   - **Vollständig übersetzt**

3. "Der Benutzer führt ein Upgrade auf Premium-Tier durch."
   - **Korrekte deutsche Formulierung**

4. "Das Gedächtnis-System speichert Erinnerungen."
   - **Konsistente Übersetzung**

## TIPPS FÜR KORREKTE VERWENDUNG

### Für technische Autoren

1. ✅ **Konsultieren Sie dieses Glossar** vor jedem neuen Dokument
2. ✅ **Hybrid-Form verwenden** bei Unsicherheit
3. ✅ **Fachbegriffe unverändert** (Backend, API, etc.)
4. ✅ **Benutzerbezogen übersetzen** (User → Benutzer)

### Für Übersetzer

1. ✅ **Kontextabhängig entscheiden** (Feature = Funktion oder Feature?)
2. ✅ **Code-Namen niemals übersetzen**
3. ✅ **Deutsche Komposita nutzen** (Datenbank, Speicherplatz)
4. ✅ **"Sie"-Form verwenden** (formal)

### Für Entwickler

1. ✅ **Code auf Englisch** schreiben
2. ✅ **Kommentare** können auf Deutsch sein
3. ✅ **Dokumentation** folgt diesem Glossar
4. ✅ **Variablennamen** auf Englisch belassen

### Neuen Begriff hinzufügen

**Prozess:**
1. Begriff in relevanter Sektion eintragen
2. Kategorie zuweisen (🟢🔵🟡🟣)
3. Verwendungskontext beschreiben
4. Beispiele hinzufügen

**Beispiel:**
```markdown
| Englisch | Deutsch | Kategorie | Hinweise |
|----------|---------|-----------|----------|
| Webhook | Webhook | 🔵 | Unverändert (API-Callback) |
```

### Bestehenden Begriff aktualisieren

**Bei Änderung:**
1. Original-Eintrag beibehalten
2. Hinweis mit Datum hinzufügen
3. In allen relevanten Sektionen aktualisieren
