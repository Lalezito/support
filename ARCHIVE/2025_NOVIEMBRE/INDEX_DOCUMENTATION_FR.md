## 📖 Glossaire Technique

### Termes Clés

| Français | Anglais | Définition |
|----------|---------|------------|
| **Séquence** | Streak | Série de jours consécutifs d'utilisation |
| **Jalon** | Milestone | Objectif de séquence (ex: 7, 30, 90 jours) |
| **Niveau gratuit** | Free tier | Abonnement sans paiement |
| **Niveau premium** | Premium tier | Abonnement payant (Cosmic/Universe) |
| **Paywall** | Paywall | Écran de conversion vers premium |
| **Points cosmiques** | Cosmic points | Monnaie virtuelle de gamification |
| **Badge** | Badge | Récompense visuelle de réussite |
| **Mémoire émotionnelle** | Emotional memory | Événement important stocké par l'IA |
| **Prédiction rétroactive** | Retroactive prediction | Prédiction vérifiable a posteriori |
| **Contexte local** | Local context | Informations culturelles et géographiques |
| **Expression régionale** | Regional slang | Argot spécifique à un pays/région |
| **Enregistrement** | Check-in | Action quotidienne pour maintenir séquence |
| **Rétention** | Retention | Pourcentage d'utilisateurs qui reviennent |
| **Conversion** | Conversion | Passage de gratuit à premium |
